Northeast Connect — Design reference v2

Mobile-first public app + desktop admin panel. Light, soft and friendly for common people; the map always stays in the centre. Status colours are used only for meaning (green Safe, amber Watch, red Danger). Alert levels: Safe → Watch → Early warning → Danger. Phone numbers 112 / 100 / 101 / 108 / 1070 / 1077 are real national helplines; every place, shelter, NGO and family contact here is demo data.
